# `charoite-graph` — пакет поиска по графу ссылок

Это метаданные дистрибутива для пакета `src/charoite_graph/`: поиск по графу
ссылок с русской морфологией для любой папки markdown, устанавливаемый **без
приложения**. Код в этот каталог не переезжает — он живёт под общим `src/`
(решение №424); здесь только `pyproject.toml` и это описание.

## Как собрать

```bash
rm -rf dist packages/charoite-graph/build packages/charoite-graph/*.egg-info
python -m pip wheel --no-build-isolation --no-deps --no-index -w dist packages/charoite-graph
```

Сборка офлайн и без изоляции сборки: интерпретатору нужен `setuptools` (>= 77 —
лицензия записана строкой SPDX) в своём окружении. Первая строка убирает следы
прошлой сборки: без изоляции `build/` старого прогона уехал бы в новое колесо.
Готовое колесо ложится в `dist/` и содержит модули `src/charoite_graph/` и один каталог
метаданных `charoite_graph-<версия>.dist-info`.

## Параметры поиска

`GraphSearch(graph_dir, embedder=…, data_dir=…, schema=…)`: роли путей — папки узлов, досье, служебные файлы,
сырьё, исключения обхода — задаёт схема хранилища (`schema`, значение `charoite_graph.graph_schema.GraphSchema`).
Без схемы — `charoite_graph.graph_schema.PLAIN`: хранилище без ролей, каждая заметка — обычный документ, ничего не
исключается. Своя схема перечисляет имена папок кортежами (строка — одно имя, пустое имя и множество — отказ
`ValueError`); значение `None` у полей `dossier_dir` и `meeting_dir` — такой роли у хранилища нет. Имена сравниваются
без учёта регистра, «ё» и формы Unicode.

## Пример

Граф из двух заметок во временном каталоге, игрушечный векторизатор и поиск. Блок исполняет тест на собранном
колесе — именно в том виде, в каком он лежит в описании артефакта (METADATA), и ждёт статус `confident` и найденный
узел.

```python
import pathlib
import tempfile

from charoite_graph.graph_search import GraphSearch
from charoite_graph.model_seam import Embedder


def vectors(texts, timeout):
    # Игрушечный векторизатор: частоты пяти букв. Настоящий — ваша модель эмбеддингов.
    return [[1.0 + text.lower().count(c) for c in "аеиор"] for text in texts]


with tempfile.TemporaryDirectory() as tmp:
    graph = pathlib.Path(tmp, "граф")
    graph.mkdir()
    (graph / "Платёжный шлюз.md").write_text("Шлюз принимает платежи и передаёт их в [[Биллинг]].\n", encoding="utf-8")
    (graph / "Биллинг.md").write_text("Биллинг выставляет счета.\n", encoding="utf-8")
    # Имя модели подписывает кэш векторов в data_dir: одно имя — одно пространство векторов.
    search = GraphSearch(graph, data_dir=pathlib.Path(tmp, "кэш"), embedder=Embedder(vectors, "частоты-букв"))
    search.refresh(force=True)   # обход графа: без него индекс пуст
    search.embed_pending()       # векторы заметок: без них выдача «не проверена семантикой»
    result = search.search("кто принимает платежи")
    print(result.status.value)   # confident — найдено и подтверждено векторами
    print(result.text)
```

## Векторы по адресу модели

Настоящий векторизатор собирает фабрика пакета — пару `Embedder` и имя модели руками собирать не нужно:

```python
from charoite_graph.embed_door import ollama_embedder

embedder = ollama_embedder("bge-m3:latest")   # Ollama на этой машине, http://127.0.0.1:11434
search = GraphSearch(graph, data_dir=cache, embedder=embedder)
```

Пачки, срок вызова и разбор ответа Ollama `/api/embed` остаются внутри. Имя модели подписывает кэш векторов в
`data_dir` — одно имя на одно пространство векторов. Собирайте векторизатор один раз: строки об отказах сервера он
говорит по разу, и эта память у каждой сборки своя.

Адрес (`url=`) фабрика пропускает через политику пакета (`charoite_graph.address_policy.guard_model_url`), по порядку:

1. адрес разбирается строго: неоднозначный (`\`, `@`, пробелы в authority, битые скобки IPv6) — отказ;
2. схема — только `http` или `https`, и для этой машины тоже;
3. адрес на этой машине (`127.0.0.0/8`, `::1`, `localhost`) — да;
4. открытый `http` — только в своей сети: IP из явного списка (`10/8`, `172.16/12`, `192.168/16`, `169.254/16`,
   `fc00::/7`, `fe80::/10`; `::ffff:a.b.c.d` судится как IPv4; туннели в интернет вроде Teredo, 6to4 и NAT64 — не своя
   сеть), либо имя без точки или из домашних доменов
   (`.local`, `.lan`, `.home`, `.internal`, `.home.arpa`), которое системный резолвер разрешает целиком в свою
   сеть; остальное — только `https`, и `allow_remote` этого не снимает;
5. любой адрес не на этой машине — и в своей сети тоже — только с `allow_remote=True` (строго `True`: строка
   `"true"` или `1` — не разрешение).

Отказ — исключение `AddressRefused` (подкласс `ValueError`) сразу при сборке, с видом отказа в поле `kind`; запросов
при этом нет. Политика окружения не читает; DNS она спрашивает только в шаге 4. `keep_alive=` — сколько сервер держит
модель в памяти; по умолчанию поле не передаётся, и решает сервер (у Ollama — 5 минут).

Транспорт по умолчанию — `urllib`: адрес на этой машине он открывает напрямую, мимо `http_proxy` окружения и прокси
системы, и не идёт за редиректом на чужой адрес; остальные адреса идут по правилам прокси, как обычно. Нужна другая
дорога — передайте свой транспорт `post=`. Дверь без политики адреса — `charoite_graph.embed_door.embedder(base_url,
model)`: адрес тогда проверяете вы.

## Командная строка

Колесо ставит команду `charoite-graph` с двумя подкомандами:

```bash
charoite-graph search ~/notes "кто принимает платежи"            # по словам, без модели
charoite-graph index ~/notes --model-url http://127.0.0.1:11434 --model bge-m3:latest --data-dir ~/.cache/charoite-graph
charoite-graph search ~/notes "кто принимает платежи" --json \
    --model-url http://127.0.0.1:11434 --model bge-m3:latest --data-dir ~/.cache/charoite-graph
```

Без `--model-url` поиск идёт по словам и честно говорит, что семантикой не проверено (статус `unverified`); кэша
при этом нет, и на диск не пишется ничего. Адрес `--model-url` проходит ту же политику, что фабрика (см. выше):
не эта машина — только с `--allow-remote`, открытый `http` — только в своей сети. Рубильник приложения
(`CHAROITE_NO_CLOUD`) на команду не действует: эту переменную она не читает. `--model-url` требует `--model` и `--data-dir`: имя модели подписывает
кэш векторов, каталог кэша задаёте только вы — путей из окружения команда не берёт, `~` раскрывает оболочка. Из окружения
берутся только язык сообщений argparse (`LANGUAGE`/`LC_*`/`LANG` через gettext) и прокси `urllib` для адреса вне этой машины (адрес на этой машине команда открывает напрямую, см. выше); имя из шага 4 политики адреса разрешает системный резолвер (на Linux glibc при этом читает `HOSTALIASES`, `LOCALDOMAIN` и `RES_OPTIONS`). Открытый `http` в свою сеть команда, как и адрес на этой машине, открывает напрямую, мимо прокси: иначе прокси увёл бы текст заметок наружу.
`index` собирает векторы заметок в `--data-dir`, `search` их читает и спрашивает вектор запроса. `--json` печатает
ответ словарём: `ready`, `status`, `reason`, `text`, `sources` (пути показанных заметок от корня папки), `total` и
охват (`skipped`, `unread`, `service`).

Коды выхода: 0 — ответ дан (статус поиска — в выводе); 1 — `index` собрал векторы не для всех заметок (причина в
stderr); 2 — аргументы или отказ политики адреса модели (причина в stderr); 3 — в папке нет прочитанных заметок `.md`. Кэш хранит пути и векторы заметок: на время
работы команда ставит процессу маску `0o077` — файлы, которые она создаёт, достаются только владельцу; созданное
раньше библиотечным вызовом она не перекрашивает. Библиотечный вызов
`GraphSearch` без команды пишет кэш по маске вызывающего. Запрос к модели идёт дверью пакета: адрес на этой машине — мимо прокси окружения и системы, без редиректа на чужой
адрес; остальные адреса — по правилам прокси `urllib` (см. выше).

## Что сверяет тест колеса

Точку входа `charoite-graph` из `entry_points.txt` артефакта — запуском под пробой пакета, а не сверкой текста. Метаданные артефакта против объявления (`Name`, `Version`, `Requires-Python`, `License-Expression`,
`Requires-Dist`, `License-File` — строкой как есть: каноническую форму пишет инструмент сборки, объявление обязано
быть в ней), тело METADATA против этого README, текст лицензии в колесе против файла, сторонние импорты пакета
против `dependencies` и `dependencies` против корневого манифеста приложения.
