# Devlog

Источник страницы https://charoiteai.github.io/Charoite_audio/ — эта папка.
Сайт собирается из неё workflow `pages.yml` при пуше в `main`, поэтому
правка публикуется обычным PR, а не отдельным коммитом в ветку сборки.

Новая запись — файл `_posts/ГГГГ-ММ-ДД-заголовок-латиницей.md` с шапкой:

```yaml
---
layout: post
title: "Заголовок"
date: 2026-08-19
---
```

Проверить локально (не обязательно, сборка всё равно пройдёт в CI). Версии
Jekyll и плагинов закреплены в `devlog/Gemfile` — тем же набором собирает
workflow, поэтому локально ставим через bundler, а не `gem install`:

```bash
cd devlog
bundle install
bundle exec jekyll serve      # http://127.0.0.1:4000/Charoite_audio/
```

Ветка `gh-pages` больше не источник: до 20.08 в ней лежал уже собранный
сайт, и правка в одном месте с публикацией из другого могли разойтись
молча. Ветка оставлена как архив; трогать её не нужно.
