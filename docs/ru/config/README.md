# Пресеты конфигурации

*[English](../../../config/README.md) · [**Русский**] · [中文](../../zh/config/README.md)*

Скопируйте один пресет в `config/config.yaml`, затем впишите `sufler.user_name` и `sufler.graph_dir`.

- `config.example.yaml` — русский дефолт: GigaAM STT (русский SOTA), документы по-русски. Стартует с лёгкого набора моделей для 8–16 ГБ (`qwen3.5:4b` во всех ролях); профили для 32 и 64 ГБ перечислены в самом файле.
- `config.example.en.yaml` — английский: Parakeet STT, документы и роль суфлёра по-английски.
- `config.example.zh.yaml` — китайский: Whisper STT из коробки (SenseVoice распознаёт китайский лучше: `.venv/bin/python scripts/get_models.py --stt sensevoice`, затем `stt.backend: sensevoice`), документы по-китайски; Qwen (LLM по умолчанию) в китайском нативен.

Английский и китайский пресеты по-прежнему стартуют с основной модели `qwen3.6:35b-a3b` (около 23 ГБ) — это машины от 32 ГБ; на Mac поменьше примените в приложении профиль полегче или поменяйте `llm.model` руками — см. [«Модели»](../MODELS.md).

Мастер первого запуска в приложении копирует сам: создаёт `config/config.yaml` в папке данных из `config.example.yaml` — единственного пресета внутри бандла — и вписывает ваше имя, папку графа и выбранный набор моделей. Для английских или китайских встреч начните с соответствующего пресета: у них другие STT-бэкенд, язык и промпты. Вложенный контур готового приложения запускает только GigaAM и SenseVoice — Parakeet английского пресета и Whisper, стоящий по умолчанию в китайском, требуют установки из исходников или вложенного контура, собранного с `--extras` (см. [«Установку»](../SETUP.md)).

Каждый ключ задокументирован прямо в файле. Сам `config.yaml` в git-игноре — ваши настройки не покидают машину.

Здесь же лежат кейсы бенча памяти (`scripts/memory_bench.py`):

- `memory_bench.example.yaml` — формат: вопрос и факты (`must`), которые обязаны быть в ответе. Скопируйте в `config/memory_bench.yaml` и наполните вопросами по своему графу; его гоняет ночной цикл.
- `memory_bench_demo.yaml`, `memory_bench_demo_en.yaml`, `memory_bench_demo_zh.yaml` — кейсы для демо-графов (`--demo`, `--demo-en`, `--demo-zh`); см. [демо](../demo/README.md).
