# Возможности

*[English](../FEATURES.md) · **Русский** · [中文](../zh/FEATURES.md)*

## Во время встречи

- **Напоминание о записи** — опциональная интеграция с календарём напоминает включить запись в начале запланированного звонка.
- **Системный звук из коробки (ScreenCaptureKit)** — захватывает звук звонка (а с macOS 15 и микрофон) напрямую без виртуальных драйверов; BlackHole остаётся запасным вариантом для терминала или при отказе в правах, с явным уведомлением.
- **Живая стенограмма** — реплики склеиваются в абзацы по говорящим; подряд идущие фразы одного голоса идут без повторения префикса, а пропуски звука явно отмечаются.
- **Живая диаризация и имена (`src/speaker_names.py`)** — с первых секунд ставит метки «Собеседник 1/2/…», а затем автоматически подставляет имена, когда участники представляются или обращаются друг к другу (с вето по регистру голоса; отказ модели не маскируется под успех). Подробности: [DIARIZATION.md](DIARIZATION.md).
- **Нить встречи** — единое полотно, растущее по мере появления тем: `●` тема, `-` тезис, `⚑` решение/срок, `?` открытый вопрос, `⏮` отсылка к прошлой встрече из архива с датой. Прошлые темы сворачиваются со счётчиком, повторы отсеиваются. При `sufler.live_feed: true` работает экспериментальная хронологическая лента (см. [live-feed.md](../live-feed.md)).
- **Мгновенные ответы (`⚡`) и живые подсказки** — ловит вопросы собеседника и вплетает короткий локальный ответ в нить вместе с контекстом темы, историей из архива и открытыми вопросами.
- **Живой контекст из архива** — ищет по графу знаний по мере проявления темы и выводит связанных людей, системы, решения и прошлые обсуждения.
- **Стартовый бриф** — заполняет карточку подсказок до начала разговора по календарю и прошлым заметкам.
- **Автотезисы и живой черновик минуток** — выделяет 📌 контрольные точки (решения, сроки, поручения) и 💭 ключевые мысли, обновляет черновик протокола примерно раз в 10 минут.
- **Вопрос ассистенту** — произвольный вопрос прямо во время встречи по текущей стенограмме и памяти графа (`src/brain.py`).
- **Решающий гейт в тени (opt-in, исследование)** — `sufler.decision_gate_shadow: true` оценивает уместность мгновенного ответа без записи текста разговора (`scripts/gate_bench.py`, см. [research/decision-gate.md](../research/decision-gate.md)).
- **Опциональная помощь облака (`☁️`, выключена по умолчанию)** — `cloud_live` и `cloud_hints` (`src/privacy.py`) дают второе мнение или точечно уточняют строки нити с подсветкой правок (`==...==`).

## После встречи (автоматически)

- **Уточнённый разбор** — при включённом `sufler.refined_debrief` «Разбор» собирает заключение из Живой нити и сверяет имена, факты и договорённости с итоговой стенограммой. Поздние поправки учитываются в выводах. Пометка «Требует уточнения» стоит рядом со спорной деталью. Дословные реплики можно прочитать во вкладке «Стенограмма». Если встреча не помещается в контекст локальной модели, «Разбор» показывает проверенные выводы по ходу разговора и сообщает об этом.
- **Поствстречная пересборка диаризации** — повторно размечает полные записи обоих каналов после Стопа (по умолчанию sherpa-onnx, опционально Nemotron через `sufler.diarize_backend: nemotron`, `src/diarize_nemotron.py`). Незавершённые пересборки и записи без речи видны явно.
- **Многослойные документы** — генерирует plain-markdown в стиле BLUF на выбранном языке (`sufler.language: ru|en|zh`, поддерживается свой `sufler.minutes_template`): одноминутная **Сводка** → **Минутки** → **Разбор** → полная **Стенограмма**, в папках архива (`YYYY-MM-DD HH-MM — Тема`) с переносной карточкой встречи.
- **Нормализованные поручения** — поручения в минутках (авточерновик, ручной `scripts/protocol.py` и MCP) детерминированно приводятся к чекбоксам `- [ ]` только для реальных участников, чтобы надёжно попадать в окно Задач. Старые файлы конвертируются через `scripts/fix_action_items.py`.
- **Самообновляемый граф знаний (`src/charoite_graph/graph_nodes.py`)** — создаёт и обновляет узлы Obsidian (Встречи, Люди, Системы, Ядра, Блокеры); нейтральные метки и разовые фоновые упоминания не превращаются в узлы людей.
- **Сохранность ручных правок и восстановление** — автоматические минутки пересобираются после диаризации (предыдущая версия уходит в `transcripts/.prev/`), а правленные вручную сохраняются и получают только восстановленные имена. Зависшая модель, падение и забытая тихая запись обрабатываются автоматически.
- **Опциональный облачный разбор (`cloud_enrich`, `scripts/cloud_review.py`)** — контролируемый разбор встречи с таймаутом и лимитами при явном включении.
- **Поствстречный хук** — `sufler.post_meeting_hook` запускает вашу команду после завершения обработки.

## Вне встреч

### Рабочее пространство, библиотека и поиск

- **Единое окно macOS (`app/`)** — вкладки «Сегодня» (капсула записи и экран предподготовки), «Библиотека встреч» (лента карточек с полосой календаря, сводкой статусов, поиском и действиями: копировать безопасную сводку, переименовать через UI или `scripts/rename_meeting.py`, повторить обработку, забыть встречу через `scripts/forget_meeting.py`), «Память» (потоковые ответы по архиву с чипами источников и историей), «Задачи» (все чекбоксы графа с поиском и сроками) и «Настройки».
- **Вопросы по архиву и брифы (`src/brain.py`, `src/charoite_graph/graph_search.py`)** — гибридный лексико-семантический поиск (`bge-m3`, `scripts/graph_search_index.py`) с русской морфологией, поддержкой CJK, приоритетом досье и лимитом 40 % контекста на один источник.
- **Ночной цикл (`scripts/nightly.sh`)** — подключается через `launchd` в один клик из Настроек: обновляет досье по темам (`src/charoite_graph/dossier.py`, `scripts/nightly_dossier.py`, опциональная облачная ревизия `scripts/nightly_dossier_review.py`), проводит ревизию ядер Tier-3 (`src/tier3.py`, `src/nli.py`, `scripts/tier3_cores.py`), чистит дубли (`scripts/dedup_graph.py`, `scripts/dedup_archive.py`), проверяет граф (`scripts/graph_doctor.py`) и собирает утренний бриф (`scripts/morning_brief.py`).
- **Три движка чата (`src/llm.py`)** — `llm.engine: ollama` (по умолчанию), MLX-сервер или opt-in облачный шлюз (`sufler.cloud_engine: true`).
- **MCP-сервер для Claude Code** — отдаёт статус, стенограмму, подсказки, минутки и обновление графа строго в пределах `CHAROITE_ROOT`.

### Диктовка, заметки и импорт

- **Глобальная диктовка (`⌥⌘D`)** — локальное распознавание со вставкой в исходное окно и восстановлением буфера обмена (включая картинки). Никогда не вставляет в поля паролей (через Accessibility); на macOS 26+ показывает живую полосу черновика без перехвата фокуса, пока GigaAM готовит финальный текст.
- **Голосовые заметки (`⌥⌘N`) и дневник (`⌥⌘J`)** — надиктованные мысли очищаются локальной моделью и раскладываются в граф или личный дневник.
- **Импорт записей (`scripts/import_meeting.py`)** — импорт аудио (`m4a`/`wav`/`mp3`), текстов (`txt`/`md`) или субтитров Zoom/Teams (`vtt`/`srt`) через CLI, вкладку «Внешняя запись», отслеживаемую папку или мост iPhone Voice Memos (`audio.voice_memos_bridge`). Дата встречи берётся из метаданных медиа до mtime файла.
- **Словарь замен (`sufler.vocabulary`)** — исправляет термины и имена, искажаемые STT, во всех документах сразу.
- **Многоязычное STT** — GigaAM (русский), SenseVoice (китайский и ещё 4 языка), а также Parakeet и Whisper при запуске из исходников.

### Мобильные компаньоны

- **Компаньон iPhone (`app-ios/`)** — фоновая запись с Live Activity и Dynamic Island, восстановление после входящего звонка, сторож зависшей записи, очередь отправки в iCloud Drive с ручным Share, плюс лента встреч и чекбоксы задач.
- **Компаньон Android (`app-android/`)** — фоновая запись 16 кГц mono WAV с локальной очередью, лентой встреч и задачами через любую синхронизацию папок (без сетевых разрешений).

### Установка, диагностика и обновления

- **Запуск без терминала** — встроенный CPython внутри `Charoite.app`, пресеты моделей под объём RAM, установка Ollama и моделей кнопкой (`scripts/get_models.py`, `scripts/install_engine.py`) и предстартовая проверка готовности (`scripts/doctor.py`).
- **Сводка здоровья и интеграция с macOS** — иконка в меню-баре сводит состояние записи, обработки, Ollama и ночи; удерживает сон во время записи; предупреждает о нехватке диска, памяти и режиме энергосбережения.
- **Безопасные обновления приложения** — проверяет релизы GitHub (отключаемо), сверяет ed25519-манифест мейнтейнера и подпись Apple Developer ID, и не перезапускает приложение во время записи.
- **Единая дизайн-система** — общие токены и семиролевая шкала кнопок для macOS и iOS (см. [DESIGN.md](DESIGN.md)).

## Утилиты (`scripts/`)

Инструменты обслуживания, миграции, диагностики и бенчмарков (подробнее в [scripts/README.md](scripts/README.md)):

| Скрипт | Назначение |
|---|---|
| `scripts/install_engine.py` | Установка изолированного окружения движка диаризации (например, `nemotron`) |
| `scripts/get_models.py` | Загрузка и проверка контрольных сумм ONNX-моделей STT и диаризации |
| `scripts/doctor.py` | Полная проверка готовности (рантайм, звук, Ollama, модели, NLI, граф) |
| `scripts/graph_doctor.py` | Аудит целостности графа знаний, ссылок и заглушек |
| `scripts/dedup_graph.py` | Ночная дедупликация файлов графа (вызывается из `scripts/nightly.sh`) |
| `scripts/dedup_archive.py` | Очистка дублей папок архива и конфликтных копий |
| `scripts/merge_graphs.py` | Безопасное слияние двух графов с редиректами |
| `scripts/migrate_placeholders.py` | Миграция старых нейтральных меток спикеров |
| `scripts/fix_action_items.py` | Нормализация старых поручений в чекбоксы `- [ ]` |
| `scripts/forget_meeting.py` | Полное удаление встречи из стенограмм, архива, записей и бэкапов графа |
| `scripts/rename_meeting.py` | Переименование встречи в стенограмме, sidecar, архиве и графе |
| `scripts/cloud_review.py` | Контролируемый облачный разбор встречи (вызывается конвейером графа) |
| `scripts/decision_evidence_audit.py` | Read-only аудит цитат решений и ссылок замен |
| `scripts/memory_bench.py` | Проверка качества поиска и ответов (`--demo`, `--demo-en`, `--demo-zh`) |
| `scripts/memory_case_suite.py` | Проверка эталонных демо-вопросов памяти и экспорт лексического поиска |
| `scripts/retrieval_compare.py` | Офлайн-сравнение ранжирования на замороженных оценках |
| `scripts/runtime_profile.py` | Профилирование локальных LLM (Ollama, MLX) через транспорт Чароита |
| `scripts/bench_models.py` | Бенчмарк моделей на сценариях Чароита |
| `scripts/stt_bench.py` | Бенчмарк локальных бэкендов STT |
| `scripts/diar_bench.py` | Расчёт DER диаризации на синтетике или реальном аудио |
| `scripts/gate_bench.py` | Оценка теневого решающего гейта |
| `scripts/nemotron_shadow_replay.py` | Прогон записи через потоковую тень Nemotron |
| `scripts/nemotron_shadow_check.py` | Сравнение журнала тени Nemotron с финальной разметкой встречи |

## Формат документов

Все документы — обычный markdown, читаемый без рендеринга: списки с жирными ключами вместо широких таблиц, короткие блоки, стабильная структура и принцип BLUF (главное в начале): Сводка (1 мин) → Минутки → Разбор → Стенограмма.
