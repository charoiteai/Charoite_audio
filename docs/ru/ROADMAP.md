# Роадмап Charoite

*[English](../../ROADMAP.md) · **Русский** · [中文](../zh/ROADMAP.md)*

Local-first, в примерном порядке приоритетов. Без дат — качество важнее
дедлайнов.

Принцип дизайна, который стоит проговорить: **никакой голосовой
биометрии**. Узнавание спикеров остаётся социальным — представления и
обращения в самом разговоре, — а не хранимыми отпечатками голоса.
Склейка кластеров одного голоса живёт в памяти в пределах одной записи
и потом выбрасывается.

## Ближайшее

- **Полные английское и китайское лица** — движок и macOS-интерфейс уже говорят на всех
  трёх языках (STT Parakeet/Whisper, документы `language: en|zh`,
  содержимое графа, подсказки и минутки; для Qwen китайский родной;
  `config.example.{en,zh}.yaml`; README ×3 и переведённые доки как
  парадные двери). Осталась последняя миля: одинаковый разбор секций
  саммари и карточки не только на русском, каталоги строк iOS и скриншоты
  под каждый язык для README.
- **Китайский SOTA-бэкенд STT** — SenseVoice/Paraformer (FunASR) через
  sherpa-onnx как вариант `stt.backend`: заметно ниже CER на китайском,
  чем у Whisper, и та же полностью локальная история, что у GigaAM для
  русского.

- **Компаньон для iPhone, завершение v1** — рекордер уже отгружен
  (app-ios/): лента встреч и чекбоксы задач из графа, Live Activity в
  Dynamic Island (таймер + стоп откуда угодно), TestFlight.
- **Прямая доставка на Mac по Wi-Fi** — телефон передаёт записи демону
  на Mac по локальной сети (Bonjour, код сопряжения); iCloud становится
  опциональным фолбэком, а не путём по умолчанию.
- **Ответы по архиву с оглядкой на граф** — подтягивать в контекст
  ответа соседей найденных узлов в один переход (человек → его встречи →
  решения), плюс локальный реранкер поверх верхних кандидатов.

- **Тюнинг склейки осколков диаризации** — склейка одного голоса в
  пределах записи уже отгружена (30 кластеров → 12 на реальной очной
  встрече); ужать пороги на большем объёме живых данных.

## Средний горизонт

- **Порт на Windows** — демон это Python + ONNX, а протокол доставки
  платформенно-нейтрален (mDNS + TLS); работа — нативная оболочка и своя
  история захвата системного звука вместо BlackHole.
- **Компаньон для Android: прямая доставка** — ядро компаньона отгружено
  (app-android/): запись, лента встреч, задачи, доставка в выбранную
  папку. Осталась передача на Mac по локальной сети (NsdManager + TLS,
  общий протокол с iPhone); до тех пор папку синхронизирует Syncthing.
- **Android: compileSdk 36** — сборка идёт против API 35, а свежие androidx
  (activity 1.13, lifecycle 2.11, Compose BOM 2026) требуют 36. Обновление
  осмысленное — планшеты уже на Android 16, — но его надо делать с проверкой
  фоновой записи на устройстве, а не принимать бампами от бота.

- **Живой режим компаньона** — телефон стримит звук встречи на Mac и
  зеркалит живую стенограмму и подсказки у себя на экране.
- **Релиз в App Store** — после того как лента встреч сделает v1
  ощутимо завершённой (сначала TestFlight).
- **Упакованный просмотрщик графа** — листать граф встреч без Obsidian.

## Сделано (недавнее)

- Установка без терминала: приложение несёт переносимый CPython **и код
  самого демона** внутри бандла, а `CHAROITE_ROOT` держит записи,
  стенограммы и конфиг в папке пользователя; мастер первого запуска пишет
  конфиг и ставит модели (август 2026)
- Системный звук через ScreenCaptureKit: ни драйвера, ни Multi-Output, ни
  агрегатных устройств — одно системное разрешение. Core Audio tap остаётся
  выключенным резервом после того, как четырежды заклинил `coreaudiod` на
  macOS 26.5 (август 2026)
- Наборы моделей под память машины: мастер первого запуска предлагает и
  ставит их сам, вместо комментария в конфиге (август 2026)
- Единая шкала кнопок по всему приложению (семь ролей, три размера) и
  второе окно, которое рисуется так же, как первое (август 2026)
- Полный путь встречи в macOS-интерфейсе: таймер и состояние в меню-баре,
