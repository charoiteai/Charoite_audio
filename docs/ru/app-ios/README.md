# Charoite для iPhone — приложение-компаньон

*[English](../../../app-ios/README.md) · [**Русский**] · [中文](../../zh/app-ios/README.md)*

Телефон — микрофон на столе, мозг остаётся на Mac. SwiftUI-компаньон
(iOS 17+, работает от iPhone 12), который записывает встречи, голосовые
заметки и дневник и читает граф знаний обратно — а всё тяжёлое (STT,
диаризация, LLM, сборка графа) выполняется на вашем Mac.

## Что умеет

- **Запись** — три типа: Встреча / Заметка / Дневник. Фоновая запись
  (старт с экрана, дальше можно блокировать телефон или уходить в
  другие приложения), живой индикатор уровня, таймер Live Activity в
  Dynamic Island и на локскрине — со **Стопом** прямо в плашке: телефон
  остаётся лежать экраном вниз, а запись кончается вместе со встречей.
- **Слушает сразу** — открыли приложение, и запись уже идёт (шестерёнка →
  «Писать сразу при открытии», по умолчанию включено; тип — последний
  выбранный; работает после выбора папки доставки). Открыли во время
  звонка? iOS оставляет микрофон звонку, и приложение взводится:
  показывает «жду микрофон» и стартует само в момент, когда звонок
  кончится, — без второго нажатия, пока приложение открыто: свёрнутое
  приложение iOS стартовать не даёт, но вернитесь в течение 30 минут — и
  оно стартует при возврате. Отмена — той же большой кнопкой.
- **Старт без рук** — App Intent «Начать запись в Charoite» для Siri,
  Команд, кнопки действия и Back Tap. Из фона iOS запись не запускает:
  интент открывает приложение, и оно стартует сразу. Чего не может ни
  одно приложение на iPhone: записать сам звонок — микрофон принадлежит
  звонку; звонок посреди записи — пауза. Когда звонок кончился, приложение
  ждёт микрофон до минуты (после долгого звонка iOS отдаёт его через
  несколько секунд, а не сразу) и продолжает тот же файл; если вход так и
  не вернулся, файл закрывается, а встреча продолжается новым. Второй
  звонок внутри этой минуты отменяет ожидание, так что сам отсчёт никогда
  не режет файл, пока iOS сообщает, что звонок идёт. Открытие приложения
  во время паузы этот отсчёт не запускает: до минуты оно пробует вход по
  той же лестнице, без ротации, и продолжает тот же файл, как только
  микрофон вернулся. Если новый файл не стартует, потому что вход ещё
  занят, старт взводится; в фоне взвод сам не сработает (iOS усыпляет
  приложение), поэтому запись подхватится, когда приложение откроют снова
  или система даст ему время. Звонки пишет Mac.
- **Сторож вставшей записи** — если длительность файла перестала расти
  дольше трёх секунд (звонок, прерывание, отобранный микрофон), экран
  говорит об этом оранжевым. Прежняя сборка считала время по стенным
  часам: на экране бежали тридцать минут, а в файле осталась сорок одна
  секунда, и узнать об этом было неоткуда. Вне звонка приложение само
  пробует поднять запись; после трёх неудачных попыток закрывает файл и
  продолжает встречу новым. Так же поступают сбой кодека и перезапуск
  аудиослужбы iOS — файл сохраняется, встреча идёт в следующем; три сбоя
  кодека подряд честно останавливают запись, а не плодят пустые куски.
- **Почему запись остановилась** — у каждого закрытого файла рядом лежит
  манифест `<файл>.json`: кто закрыл, почему (кнопка «Стоп», микрофон не
  вернулся за минуту после звонка, перезапуск аудиослужбы, сбой кодека,
  застой — или стоп не зафиксирован вовсе, если приложение умерло), когда
  и сколько секунд. Он едет на Mac парой с аудио и становится событием
  следа записи встречи, так что встреча, приехавшая тремя кусками, говорит
  почему.
- **Доставка** — записи падают в папку iCloud Drive, которую вы выбрали
  один раз (та же папка, за которой Mac-приложение следит как за папкой
  импорта). Нет связи? Несгораемая очередь Outbox досылает при каждом
  запуске и после каждого стопа. Файл публикуется атомарно (копия под
  `.part`, затем переименование) и уходит из очереди, только когда iCloud
  сообщил о выгрузке копии, если iOS вообще может это сказать: «скопирован
  в папку» ещё не значит «едет на Mac». Голосовые заметки (префиксы
  `note_`/`diary_`) автоматически уходят в конвейер заметок на Mac.
- **Очередь видно целиком** — строка «В очереди записей: N» открывает
  список: что записано, когда, сколько весит. Записи старше суток
  подсвечены: обычная доставка занимает секунды, и всё, что висит дольше,
  висит уже не «сейчас уедет». Оттуда же досылка одной кнопкой.
- **Запись можно забрать руками** — кнопка «Поделиться записью» отдаёт
  файл куда угодно, а папка записей видна в «Файлах» и по кабелю
  (`UIFileSharingEnabled`). Пять последних записей остаются на телефоне
  и после доставки: «iCloud принял» не значит «Mac получил».
- **Лента встреч** — читает прямо из выбранной папки графа (вторая
  закладка): переносимые карточки встреч
  (`Встречи-архив/*/meeting.meta.json` — участники, суть, решения,
  поручения, открытые вопросы), а для старых встреч без карточки —
  `Встречи/*.md`; свежие сверху, карточка или полный текст по тапу.
  Нескачанные из iCloud файлы честно пропускаются с запросом загрузки.
- **Задачи** — все чекбоксы `- [ ]` графа одним списком; отметка
  пишется в сам markdown-файл, так что Mac, Obsidian и телефон всегда
  видят одно и то же.

## Сборка и установка

Нужны Xcode 16+ (XcodeGen пишет проект в формате, который Xcode 15 не
открывает) и [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```bash
cd app-ios
export DEVELOPMENT_TEAM=<team id>   # его читает project.yml; свой Team ID в репозитории не хранится
xcodegen generate
open CharoiteiOS.xcodeproj   # соберите на устройство
```

Сборке без подписи, как в CI, команда не нужна:
`xcodebuild … CODE_SIGNING_ALLOWED=NO build`.

Версия в настройках записи берётся из `MARKETING_VERSION` в `project.yml`
(её поднимает release-please); после `xcodegen generate` проверьте plist:
`plutil -p Info.plist | grep CFBundleShortVersionString` должен печатать `$(MARKETING_VERSION)`,
а собранный бандл — номер релиза. Номер сборки (`CURRENT_PROJECT_VERSION`,
оба таргета) release-please не ведёт: перед каждой загрузкой в App Store /
TestFlight поднимайте его руками.

Тесты: unit-таргет (парсинг графа, политики рекордера для звонков,
застоя, сбоев кодека, автостарта и манифестов остановки, очередь доставки)
и UI-тесты. Запуск на симуляторе (CI гоняет их по ночам):

```bash
xcrun simctl privacy booted grant microphone ai.charoite.CharoiteiOS
xcodebuild -project CharoiteiOS.xcodeproj -scheme CharoiteiOS \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' test
```

## Первая настройка на телефоне

1. **Вкладка Запись** → иконка лотка (↑) → выберите папку доставки в
   iCloud Drive (например, `Charoite Inbox` — папка импорта Mac).
2. **Вкладка Встречи** → иконка книг → укажите папку графа внутри
   Obsidian в Файлах.

Папки разные намеренно — доставка это куда уходят записи, граф это что
телефон читает, — поэтому и иконки у них разные: оранжевая иконка значит,
что эта папка ещё не выбрана. Оба выбора — по одному разу; security-scoped
закладки переживают перезапуски.

## Приватность

Приложение не разговаривает ни с чем, кроме ваших папок iCloud Drive.
Без аккаунтов, телеметрии и сторонних сервисов. Удалили запись из
папок — её больше нет, скрытых копий не существует.

## TestFlight

Сборка и загрузка — облачной подписью через ключ App Store Connect API
(роль App Manager; ключ НЕ в репозитории):

    export DEVELOPMENT_TEAM=<team id>
    xcodegen generate
    xcodebuild -project CharoiteiOS.xcodeproj -scheme CharoiteiOS \
      -destination 'generic/platform=iOS' \
      -archivePath build/CharoiteiOS.xcarchive archive \
      -allowProvisioningUpdates \
      -authenticationKeyPath ~/.config/charoite/AuthKey_<KEY_ID>.p8 \
      -authenticationKeyID <KEY_ID> -authenticationKeyIssuerID <ISSUER_ID>
    xcodebuild -exportArchive -archivePath build/CharoiteiOS.xcarchive \
      -exportOptionsPlist ExportOptions.plist -exportPath build/export \
      -allowProvisioningUpdates \
      -authenticationKeyPath ~/.config/charoite/AuthKey_<KEY_ID>.p8 \
      -authenticationKeyID <KEY_ID> -authenticationKeyIssuerID <ISSUER_ID>

`destination: upload` в `ExportOptions.plist` грузит билд прямо в TestFlight;
там же лежит `teamID` владельца — впишите свой. Разовые предварительные
шаги: bundle id регистрируется через ASC API (POST /v1/bundleIds — нужен
ключ с ролью App Manager, ключ роли Developer получает 403), а ЗАПИСЬ
ПРИЛОЖЕНИЯ создаётся только руками в ASC (App Store Connect → Apps → «+» →
New App); без неё экспорт падает с «Error Downloading App Information».
`ITSAppUsesNonExemptEncryption: false` (задан в `project.yml`, из которого
генерируется Info.plist) избавляет каждый билд от ручного ответа про
шифрование. Перед каждой загрузкой поднимайте `CURRENT_PROJECT_VERSION`
(см. выше).
