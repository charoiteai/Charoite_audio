# Charoite для Android — приложение-компаньон

*[English](../../../app-android/README.md) · [**Русский**] · [中文](../../zh/app-android/README.md)*

Планшет или телефон — микрофон на столе, мозг остаётся на Mac.
Compose-компаньон (Android 8+), который записывает встречи, голосовые
заметки и дневник и читает граф знаний обратно — а всё тяжёлое (STT,
диаризация, LLM, сборка графа) выполняется на вашем Mac.

## Что умеет

- **Запись** — три типа: Встреча / Заметка / Дневник. Фоновая запись
  через foreground-сервис (старт с экрана, дальше можно свернуть
  приложение), живой индикатор уровня, таймер в шторке и на локскрине,
  кнопка «Стоп» прямо в уведомлении.
- **Доставка** — записи падают в папку, которую вы выбрали один раз
  системным выбором (SAF). Ту же папку должен видеть Mac: через
  Syncthing или любой синхронизатор, на стороне Mac это папка импорта.
  Нет связи? Очередь во внутренней памяти досылает при каждом запуске
  и после каждого стопа. Повторное открытие приложения во время записи
  не трогает активный файл; после аварии он проверяется до переноса в
  очередь, а сорванная провайдером копия не оставляет недописанный WAV.
  Голосовые заметки (префиксы `note_`/`diary_`) автоматически уходят в
  конвейер заметок на Mac.
- **Лента встреч** — читает файлы `.md` из папки «Встречи» выбранного
  графа (вторая папка), свежие сверху, полный текст по тапу.
- **Задачи** — все чекбоксы `- [ ]` графа одним списком; отметка
  пишется в сам markdown-файл, так что Mac, Obsidian и планшет всегда
  видят одно и то же.

Сканирование графа и чтение файлов идут в фоне: большой граф не
подвешивает интерфейс, а повторное открытие вкладки отменяет устаревший
скан и не показывает запоздавший результат.

## Формат записи

16 кГц, моно, 16 бит, WAV — ровно то, что нужно распознаванию на Mac,
без единого перекодирования по дороге (около 115 МБ за час).

WAV выбран не из любви к размеру, а из-за обрыва: контейнер MPEG-4 без
штатного `stop()` остаётся без атома `moov` и не читается ничем, а час
чужой встречи не переснять. Заголовок WAV обновляется по ходу записи,
поэтому даже убитый системой файл остаётся валидным; при следующем
запуске приложение дописывает в нём фактическую длину.

## Сборка и установка

Нужны JDK 17 и Android SDK (compileSdk 35). Путь к SDK — в
`app-android/local.properties` (`sdk.dir=...`), файл не в репозитории.

```bash
cd app-android
./gradlew testDebugUnitTest        # разбор графа и заголовок WAV
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Проверка на живом устройстве (микрофон, сервис, целостность файла):

```bash
./gradlew connectedDebugAndroidTest
```

## Первая настройка

1. **Настройки** → «Папка доставки» → выберите папку, которую
   синхронизируете с Mac (на Mac это папка импорта Charoite).
2. **Настройки** → «Корень графа» → укажите папку Obsidian-графа —
   ту, внутри которой лежит раздел «Встречи».

Оба выбора — по одному разу: разрешения на папки переживают
перезапуски и перезагрузку.

## Приватность

У приложения нет ни одного сетевого разрешения — проверяется в
`AndroidManifest.xml`. Звук не покидает устройство иначе как через
выбранную вами папку. Без аккаунтов, телеметрии и сторонних сервисов.

## Чего пока нет

Прямой доставки на Mac по Wi-Fi: она ждёт общего протокола (mDNS +
код сопряжения + TLS), одного для iPhone и Android — см. ROADMAP.
До тех пор синхронизацию папки делает Syncthing или любой другой
синхронизатор, и приложению всё равно, какой именно.

Записи с устройств Android помечаются префиксом `android_` — по нему
в папке импорта видно, чем записана встреча.
