# Charoite.app — macOS-приложение суфлёра

*[English](../../../app/README.md) · [**Русский**] · [中文](../../zh/app/README.md)*

Нативная SwiftUI-оболочка над Python-демоном Charoite: живая стенограмма
с диаризацией, нить встречи, подсказки и Claude-панель, подготовка к
встречам и брифы, библиотека встреч с карточками результата, импорт
сторонних записей, задачи, чат с памятью графа, диктовка (⌥⌘D),
голосовые заметки (⌥⌘N) и дневник (⌥⌘J), меню-бар. По умолчанию всё
локально — как и сам демон; немногое, что может уйти с машины, перечислено
в конце.

## Сборка

```bash
cd app
./make_app.sh          # swift build -c release (arm64) + бандл + подпись
open build/Charoite.app
```

Требования: macOS 14+ на Apple Silicon, Xcode Command Line Tools
(`xcode-select --install`).

Подпись: Developer ID Application с hardened runtime и меткой времени, если
такой сертификат есть в связке (или назван в `CHAROITE_SIGN_IDENTITY`; `-` —
принудительно ad-hoc), иначе ad-hoc. С ad-hoc подписью macOS считает каждую
пересборку новым приложением: доступ к микрофону и записи экрана приходится
выдавать заново, а первый запуск требует «Открыть всё равно». Под hardened
runtime демон не наследует доступ приложения к микрофону, поэтому вложенный
интерпретатор подписывается со своими entitlements
(`Resources/entitlements/embedded-python.entitlements`).

В бандл кладётся код демона (`src/`, `scripts/`,
`config/config.example.yaml`) и, если перед этим запускали
`scripts/build_embedded_python.sh`, переносимый python-контур; без него
приложение берёт `.venv` в своей папке данных, как при установке из клона.
Версия берётся из последнего git-тега, номер сборки — из числа коммитов.
Релизная сборка (DMG, нотаризация, подписанный манифест обновления) описана в
[«Релизах»](../RELEASING.md).

Тесты: `swift test --filter '^CharoiteAppTests\.'` в `app/`. В `Probes/` лежат
живые пробы на настоящем графе и Ollama; без своих переменных окружения они
пропускаются и запускаются только руками.

## Первая настройка

1. Откройте приложение, остальное сделает мастер первого запуска: поставит
   или запустит Ollama (через Homebrew, если он есть, иначе откроет страницу
   загрузки), спросит имя и папку графа, предложит набор моделей под память
   этой машины и скачает его, предложит модель различения голосов (~80 МБ).
   Python-контур и код демона едут внутри бандла — ни `git clone`, ни venv,
   ни `pip` не нужны.
2. Настройки (⌘,), если нужно что-то поменять:
   - **Папка данных** — где лежат `config/config.yaml`, стенограммы, записи и
     модели; по умолчанию `~/Library/Application Support/Charoite`. Если
     выбранная папка — клон с `src/daemon.py`, отдельный тумблер «Запускать
     код демона из этой папки (разработка)» запускает его код вместо кода
     подписанного бандла;
   - **Ollama** — адрес сервера (по умолчанию `http://localhost:11434`);
     адрес не на этой машине отвергается, и отказ виден, пока в конфиге нет
     `llm.allow_remote: true`;
   - кнопка «Проверить» покажет, что демон, Ollama, bge-m3 и граф на месте;
   - здесь же ночной цикл (launchd-задача на 04:15), папка импорта,
     календарь и «Что уходит с машины».
3. Путь графа лежит в `config/config.yaml` (`sufler.graph_dir`) внутри папки
   данных — мастер его пишет, демон читает. Относительный путь считается от
   папки данных.

При первом «Слушать встречу» macOS спросит доступ к микрофону. Собеседник в
звонке пишется через ScreenCaptureKit: выдайте право «Запись экрана и
системного звука» и перезапустите приложение — без него пишется только ваш
микрофон. Для автовставки диктовки в активное поле дайте приложению право
Accessibility (Универсальный доступ). Доступ к календарю необязателен и
читает только названия и время событий.

Первая запись — сквозная проверка: таймер должен расти, обе стороны разговора
должны появиться в стенограмме, после «Стоп» должны сменяться реальные этапы
обработки, а итогом должна стать карточка встречи. Полный сценарий и
восстановление после ошибки — в
[практическом руководстве](../USER_GUIDE.md).

## Что где

- `Sources/CharoiteApp/App` — сцены (главное окно, окно «Чат с памятью»,
  меню-бар, Настройки), обработчик ссылок `charoite://` и переходы между
  разделами.
- `Sources/CharoiteApp/Views/Workspace` — главное окно: сайдбар, «Сегодня»,
  библиотека встреч, «Внешняя запись».
- `Sources/CharoiteApp/Views/Sufler` — раздел «Встреча» (стенограмма, нить,
  подсказки, Claude-панель) и мастер первого запуска.
- `Sources/CharoiteApp/Views/Meetings`, `Prep`, `Tasks`, `LocalChat`,
  `MenuBar`, `Settings`, `Dictation` — карточка встречи, подготовка,
  задачи, «Память», меню-бар, Настройки и превью диктовки.
- `Sources/CharoiteApp/Services` — мост к демону (NDJSON stdin/stdout,
  watchdog, авто-рестарт), захват системного звука, жизненный цикл записи и
  статус обработки, диктовка, локальный поиск по графу и семантический
  индекс, импорт, календарь, обновления.
- `Sources/CharoiteApp/L10n.swift` — строки интерфейса на русском,
  английском и китайском.

## Главное окно и меню-бар

Одно окно с сайдбаром; меню-бар, карточка встречи и подготовка переключают
разделы, а не открывают свои окна.

- **Сегодня** — кнопка записи с готовностью, состояние текущей встречи
  (запись, обработка, результат готов), подготовка к ближайшему событию
  календаря (прошлые встречи по теме, открытые поручения, последняя встреча
  по ней), последние результаты, прошла ли ночная обработка и какая версия
  работает, предложение обновиться.
- **Встреча** — стенограмма, растущая нить встречи, подсказки и мгновенные
  ответы на вопросы собеседника, «Конспект» (⌘⏎) и «Протокол» по кнопке,
  вопросы по этой встрече и графу, облачный слой Claude по желанию (с
  пометкой «уходит с машины»), таймер записи и честные этапы обработки после
  «Стоп»; чат с памятью открывается боковой панелью.
- **Встречи** — библиотека: карточки по дням с состоянием, длительностью,
  участниками и поручениями, полоса недели, поиск по саммари, минуткам,
  разборам и заметкам графа. Карточка встречи рядом — тема, дата,
  длительность, участники, суть, решения и поручения на четырёх глубинах
  (Резюме · Минутки · Разбор · Стенограмма), копирование, переход к
  стенограмме и Obsidian, согласованное переименование файлов встречи и
  повтор неудачной обработки. Лента — история статусов, до 20 запусков за
  14 дней, а не замена полному архиву графа.
- **Внешняя запись** — перетащите запись с телефона, чужую запись звонка
  или экспорт Zoom: файл копируется в папку импорта (оригинал остаётся у
  вас), очередь показывает, что ждёт, что упало (повтор, стенограмма,
  Finder) и когда обработанная копия удалится.
- **Задачи** — все поручения из минуток и заметок графа одним списком;
  отметка пишется прямо в markdown. «Мои» — первыми, старые свёрнуты,
  группировка по встрече или по сроку, бейдж открытых.
- **Память** — чат с локальной моделью (живой список моделей из Ollama);
  чип «Память графа» подмешивает найденное в графе, у каждого ответа —
  чипы источников и строка происхождения, колонка «Что знает память»
  перечисляет ядра. Тот же чат открывается отдельным окном «Чат с памятью»;
  история общая.

Меню-бар остаётся центром состояния при закрытом окне: иконка становится
красным треугольником, когда записанное под угрозой, и жёлтым кругом при
деградации без потери; меню показывает таймер, обработку, готовность и
ошибку, даёт начать и остановить запись, открыть последний результат,
повторить обработку, открыть последние встречи и «Сегодня», задать быстрый
вопрос локальной модели, включить диктовку, заметку и дневник. Встречи
индексируются в Spotlight, а `charoite://record/start`, `stop`, `toggle`,
`charoite://meeting/<id>`, `charoite://tasks` и `charoite://today` управляют
приложением из Команд или терминала. Где лежат данные и когда они
удаляются — в [«Данные и восстановление»](../DATA_AND_RECOVERY.md).

## Поиск по архиву (v2)

Вопросы и брифы ранжируются по-взрослому: стемминг русских окончаний
(плюс лёгкий английский стемминг и биграммы для китайского), IDF (редкое
слово запроса весит больше), покрытие запроса, свежесть файла (дата в
имени), приоритет дистиллятов графа над сырыми стенограммами, разнообразие
выдачи (одна встреча не занимает все слоты). Слабые совпадения помечаются
«⚠ совпадения в графе слабые» — модель не сочиняет ответ по
нерелевантным кускам. Чипы источников под ответом кликабельны: встреча
открывает свою карточку, заметка графа или досье — сам файл.

Семантический слой (bge-m3 через вашу Ollama) работает и во встроенном
поиске: индекс держит вектор на каждый блок файла, строится фоном и
обновляется по mtime (см. docs/SETUP — `ollama pull bge-m3`). Если поднят
опциональный brain-сервер (порт 8100), поиск уходит в него; без обоих —
чистая лексика.

## Что уходит с машины

По умолчанию приложение говорит только с localhost: ваш Ollama,
опциональный brain-компаньон (:8100) и демон суфлёра. Два исключения — под
вашим управлением: не чаще раза в четыре часа оно спрашивает у публичного API GitHub номер
последнего выпуска (`sufler.check_updates`, тумблер в Настройках), а
принятое вами обновление скачивается из релизов GitHub и заменяет
приложение только после проверки контрольной суммы, подписи манифеста
ключом владельца и подписи Developer ID. Под `CHAROITE_NO_CLOUD` выключено
и то и другое. Облачные слои — Claude на встрече, облачный движок чата —
включаются только вами и работают в демоне; см.
[«Приватность»](../PRIVACY.md).
