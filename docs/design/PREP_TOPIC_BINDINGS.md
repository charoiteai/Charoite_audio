# Подготовка: подтверждённая тема календарного события

В «Подготовке» пользователь может заменить поисковую тему ближайшего события
и сохранить её. Привязка влияет на связанные встречи, поручения и прошлую
встречу; сброс возвращает поиск по названию. Никаких записей в календарь.

Ключ: канонический путь графа, ID календаря, внешний ID календарного элемента
(при его отсутствии — локальный calendarItemIdentifier). Одинаковые названия
не объединяются. Внешний ID повторяющегося события позволяет повторно
использовать привязку; изменение календарной идентичности требует нового
подтверждения, автоматического переноса по похожему названию нет.

Данные хранятся в UserDefaults приложения. Переключение графа не переносит
привязки в другой граф. Повреждённые данные читаются как отсутствие привязок.
Это первый этап подготовки: только подтверждённая поисковая тема; генерация
вопросов, синтез изменений и автоматическая привязка участников не добавлены.

Проверка: `cd app && swift test --filter PrepTopicBindingsTests`.
На Mac: сохранить «Платёжный провайдер» для «Еженедельного синка»; проверить
смену поисковой выдачи и связанных задач; перезапустить приложение; сбросить
привязку. Отдельно проверить два одноимённых события разных календарей.
