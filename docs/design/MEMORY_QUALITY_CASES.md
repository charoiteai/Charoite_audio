# Контрольные вопросы памяти

Первый этап пункта 7: 18 фиксированных вопросов по существующим демо-графам
на русском, английском и китайском. Шесть категорий: решение, число,
поручение, выполненное поручение, исторический факт, вопрос без ответа.
Это открытые учебные примеры, не реальные пользовательские встречи и
не доказательство превосходства какой-либо модели.

`python scripts/memory_case_suite.py` проверяет, что все положительные
источники существуют и содержат размеченную цитату. Изменение демо-графа
не должно молча оставлять неверный эталон. Безответность — ручная разметка
набора; отсутствие цитаты её автоматически не доказывает.

`CHAROITE_ROOT=/path/to/data python scripts/memory_case_suite.py --collect`
экспортирует фактическую лексическую выдачу через штатный graphs.open_search.
Сеть, эмбеддинги и синтез выключены. ranking — структурированные источники;
abstained — политика brain.absence_only по результату поиска, не оценка
сгенерированного ответа. Сохранены статус и охват. Неудачные запросы остаются
в результатах; failed_queries > 0 даёт exit 1.

В экспорт входят judgments и run; их можно сохранить в отдельные JSON
для evaluator из ветки retrieval-model-evaluation. Один набор вопросов
не смешивать с настройкой порогов: рабочие примеры делятся на калибровочную
и отложенную части ДО выбора модели. Требуется дополнить их вопросами
с заменёнными решениями, длинной историей, омонимами людей и терминами
из реального архива; 18 демо-вопросов для этого недостаточно.
