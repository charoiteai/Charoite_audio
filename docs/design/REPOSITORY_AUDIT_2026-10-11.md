Тест документационного workflow запускает его настоящий shell-шаг в отдельном
временном Git-репозитории. Он проверяет также `skip-docs`, похожую неподходящую
метку, релизный diff и Gradle wrapper. Это сильнее поиска нужных слов в YAML.
Сторож хешей остаётся структурной проверкой: подлинность скачанного артефакта
проверяет `pip --require-hashes`, а не этот тест.

## Что убрать, что оставить

**Убрать следующим отдельным изменением:** абсолютное обещание «Nothing leaves
your Mac» из About репозитория и из формулировок процесса. README уже честно
описывает выключенные по умолчанию облачные функции и проверку обновлений.
Предлагаемое About: “Local-first AI meeting assistant with speaker diarization
and a self-updating knowledge graph. Optional cloud features are off by default.”
About — настройка GitHub, в данном PR она не изменяется.

**Сократить после измерения:** дублирование тяжёлого CI на push и PR одного
коммита. Удалять push-триггер нельзя: он обеспечивает проверку веток без PR.
Сначала снять длительность и расход раннеров за неделю, затем рассмотреть
переиспользуемые jobs и отдельный быстрый сигнал на push. Не менять имена
обязательных checks и не превращать отменённый прогон в успешный.

**Оставить:** `tests/`, `docs/design/layout.json`, проверки приватности,
мутационный гейт, переводные документы, мобильные приложения и резервный
бэкенд diarization. Большой размер или дублирование названий сами по себе
не доказывают, что это лишнее. Закрытые ветки удалять только после проверки
мержа и отсутствия уникальных коммитов; история в этом PR не переписывается.

## Первичные источники практик

- [GitHub: безопасное использование Actions](https://docs.github.com/en/actions/reference/security/secure-use):
  SHA закрепляет action неизменно; Dependabot поддерживает ссылки по SHA и
  обновляет комментарий версии на той же строке. У SHA-ссылок есть отдельное
  ограничение advisory alerts — переход не заменяет остальные security-гейты.
- [GitHub: параметры Dependabot](https://docs.github.com/en/code-security/reference/supply-chain-security/dependabot-options-reference):
  отдельные манифесты и экосистемы должны входить в конфигурацию обновлений.
- [GitHub: dependency review](https://docs.github.com/en/code-security/concepts/supply-chain-security/dependency-review):
  проверяет изменения зависимостей в PR; не является полным аудитом всех
  уже установленных зависимостей и произвольных инструментов из shell-команд.
- [websockets: proxy configuration](https://websockets.readthedocs.io/en/15.0.1/topics/proxies.html):
  WS/WSS proxy имеет приоритет перед HTTP/HTTPS proxy; `proxy=None` явно
  отключает proxy для соответствующего соединения.
