# NLI_LABEL_CONTRACT

Порядок трёх классов берётся из config.json/id2label. Нужна перестановка entailment, neutral, contradiction с индексами 0, 1, 2; generic LABEL_0, пропуск файла или неоднозначность отказывают в готовности. Старые установки без config.json должны восстановить метаданные из того же экспорта, что и ONNX. Угадывать порядок нельзя. Выход ONNX проверяется на три конечных логита.

На main все 6 регрессий красные: переставленные классы инвертируют ответ, отсутствующие или неоднозначные метаданные принимаются.
