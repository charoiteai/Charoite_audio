# NLI_GATE_SUPPORT

Для NLI zero-shot относительная оценка каждой гипотезы ограничивается её абсолютной поддержкой. 0.009 и 0.001 дают оценки 0.009 и 0.001, а не 0.9 и 0.1. Остаток массы означает неизвестность; оценки могут суммироваться меньше единицы. Это не калиброванная вероятность классов. Обученная голова и generic normalize сохраняют прежнюю нормализацию; входные значения за пределами [0, 1] отклоняются.

Каскад с высоким порогом эскалирует слабую поддержку. Одновременно поддержанные гипотезы остаются неоднозначными. Теневой гейт продолжает работать в тени; поправка не включает его для живых решений. Калибровка порога требует отдельной разметки.

На main две регрессии абсолютной поддержки красные: confidence 0.9 и 0.9983 вместо верхних границ 0.009 и 0.6.
