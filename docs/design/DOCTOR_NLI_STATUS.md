# Диагностика NLI без скрытого инференса

Доктор проверял Nemotron, но не показывал состояние NLI. Обычный запуск теперь называет недостающие или пустые файлы и пакеты. Наличие файлов не выдаётся за работающий инференс. Отсутствие опционального NLI — предупреждение, не авария всего приложения.

`--probe-nli` проверяет только локальный NLI через существующую дверь `nli.judge().ready()`. Конфигурация LLM и её сервер не проверяются; веса не скачиваются. Код 0 означает успешную канарейку; недоступность, отказ и отложенная проба дают код 1. Параметры --probe-nli и --restart-llm взаимоисключающие.

Перед загрузкой проверяется лок демона. Если встреча идёт, проба откладывается. Это проверка на входе: проба не прерывается, если встреча стартовала позже.
