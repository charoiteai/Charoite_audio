# Шапка задач: отдельная доработка UX

База: `5149770552b2b49c8b48dec12ad44a8351028cbf`. Проверка по коду,
без живого macOS-прогона.

В одной строке TasksView находились название, сводка, переключатель
группировки, поиск фиксированной ширины 210 pt, checkbox и две кнопки.
Detail допускает минимум 640 pt: размер окна сам по себе не гарантирует,
что все эти элементы остаются доступны.

Изменение: сводка, копирование и обновление в первой строке; фильтры —
во второй. Поле поиска занимает доступную ширину, группировка ограничена
240 pt. Добавлены явные названия для VoiceOver у группировки, поиска,
копирования и обновления. Работа Markdown и правила фильтров не меняются.

Основание: [Apple — Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)
и [Searching](https://developer.apple.com/design/human-interface-guidelines/searching).
Разделение строк — применение рекомендаций к найденной геометрии,
а не готовый универсальный шаблон из источника.

Проверки на Mac: ширина detail 640/760/980 pt; RU/EN/ZH; длинная сводка;
фильтр одной встречи; ввод поиска; checkbox «Сделанные»; обе группировки;
копирование видимых открытых задач; обновление; Tab/VoiceOver.
Сборка и существующие тесты задач — через swift-tests CI.
