# Мобильное приложение и доделки macOS — макеты, август 2026

Экраны iPhone-компаньона v1 и три «не начатых» экрана macOS из ревизии
`UI_REVISION_2026-08.md`. Токены не меняются: `accent #6366F1`,
`violet #8B5CF6`, `sky #0EA5E9`, `ok #059669`, радиусы 8/12, системный SF
(`app-ios/Sources/CharoiteiOS/Theme.swift` — источник истины).

Макет: [mobile-mockup.html](mobile-mockup.html) — один файл, открывается
в браузере, все экраны рядом. Копия — на трёх языках приложения
(RU/EN/中文): словари лежат в логике макета, по умолчанию русский.

## Экраны

1. **Запись — покой.** Одна кнопка с фирменным радиальным градиентом
   (`Theme.record`) и мягкой тенью акцента; сегмент Встреча/Заметка/Дневник;
   очередь — вход («В очереди записей: 2»), не серая строка.
2. **Запись — идёт.** Системный красный, тень выключена; моноширинный
   таймер `weight(200)`; живой метр уровня (12 столбиков); подпись «экран
   можно гасить»; сторож файла — оранжевая карточка, когда файл не растёт.
3. **Встречи.** Группы «Сегодня / На этой неделе / Раньше»; у каждой
   строки дата, длительность, число голосов и поручений; «собирается на
   Mac» — пульсирующая индиго-точка; ошибка обработки подписана словами.
4. **Карточка встречи.** Сегмент «Резюме · Минутки · Разбор · Стенограмма»
   — четыре глубины чтения одной встречи; «Решили» с ⚑; «Открытые вопросы»
   на лавандовой поверхности памяти с чипом «второй раз без ответа»;
   поручения с исполнителем и `DueChip`; внизу источник
   (`Встречи/2026-08-16_1120.md`), «Пересобрать результат», «Забыть встречу».
5. **Задачи.** Сводка «2 просрочено · 9 открыто · 3 сделано» вместо голого
   счётчика; переключатель «По встрече / По сроку»; группы — карточки
   встреч со ссылкой «К встрече»; сделанное приглушено и зачёркнуто,
   но на месте.
6. **Очередь доставки — лист.** Видно всё, что не уехало: тип, время,
   размер; «Поделиться» у каждой записи; ждущее дольше суток — оранжевым
   с объяснением и действием.
7. **Тёмная тема.** Фиолетово-угольная (`#14121F`/`#232047`), не серая.

## macOS: доделки «не начато» из ревизии

1. **Память** (`LocalChatView`) — сделано 24.08. Ответ — белая карточка
   с волосяной рамкой (владелец выбрал гамму библиотеки встреч вместо
   лаванды) с чипами источников — встреча, узел, досье; строка «локально ·
   модель · время · сколько встреч в контексте»; шапка: «Память графа» —
   чип-состояние, справа «Ollama отвечает · 0 запросов в сеть»; правая
   колонка «Что знает память» (встречи/узлы/досье + ядра со статусами,
   при ширине ≥760 pt); слабые совпадения — «⚠» без чипов.
2. **Задачи** (`TasksView`) — сделано 21.08. Сводка «просрочено /
   открыто / сделано» вместо голого счётчика (три числа не пересекаются);
   переключатель «По встрече / По сроку» с памятью выбора; корзины срока —
   Просрочено / Ближайшие 7 дней / Позже / Без срока / Сделанные, в
   корзинах у строк подпись встречи; просрочка оранжевым (`Theme.overdue`),
   `DueChip` «просрочено · 13.08 (3)» был раньше. Политика —
   `TasksScreenPolicy` (тестируется без UI); макет —
   Charoite Design System → macOS → tasks-screen.
3. **Библиотека встреч** (`MeetingLibraryView`) — сделано 23.08. Карточная
   лента в workspace с группами «Сегодня · На этой неделе · Раньше» и
   сводкой состояний над ней; у карточки точка состояния, длительность,
   участники и поручения числами с источником, суть, слои «Резюме · Минутки
   · Разбор · Стенограмма» мини-сегментом (клик открывает карточку на этой
   глубине, отсутствующая — пунктиром), «собирается» — пульс, ошибка
   обработки подписана словами и с «Повторить обработку» на месте. Политика
   — `LibraryScreenPolicy` (тестируется без UI); макет — канвас «Библиотека
   встреч» (Claude Design, 23.08): окно с лентой, пять состояний строки, два
   пустых состояния.

## Правила ревизии на телефоне

1. Поверхность обозначает происхождение: белая — сейчас и локально,
   лаванда — память графа. Sky на телефоне не появляется: компаньон
   не разговаривает ни с чем, кроме папок iCloud.
2. У каждого числа — срок, имя или источник.
3. Пустые состояния и предупреждения говорят, что случилось и что нажать;
   очередь и сторож записи — видимые входы, не тихие строки.
