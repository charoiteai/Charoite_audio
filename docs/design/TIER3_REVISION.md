# Ревизия ядер графа (Tier 3)

Документ устройства ревизии. Хроника правок — в истории git и описаниях PR, здесь только то, как ревизия работает
сейчас и почему так.

## Зачем
Экстрактор заводит ядро по названию темы из каждой встречи. Сквозная тема со временем расщепляется на двойников с
размазанной хроникой. Ревизия ищет такие пары и предлагает или делает порядок.

## Кто судится
Только ядра со своей сутью: секцией `## Суть` или `## Задача одной фразой`, которую пишет человек
(`load_cores`, `essence_src == "секция"`). Ядро от `upsert_core` несёт лишь `## Статус`. Автостатус шаблонный, и у
разных тем он следует друг из друга на 0,93–1,00: в замере 05.10 из 10 уверенных пар явных дублей было 0. Ядро без
своей сути не попадает ни в эмбеддер, ни в NLI.

Если судимых ядер меньше двух или у ядер фокуса нет своей сути, исход `no_work`. Причина названа словами
(«своя суть у N из M ядер»). Проверка «судить нечего» стоит раньше проверки отказа судьи: граф без работы не
выглядит как «нет модели».

## Как судится
1. Кандидаты: косинус bge-m3 по `«<имя>. <суть>»` не ниже `EMB_PREFILTER` (0,55).
2. Каждую пару судит NLI (`src/nli.py`) в обе стороны.
3. Категории:

| Исход | Условие | Действие |
|---|---|---|
| ДУБЛЬ | обоюдное следование ≥ `MERGE_T` (0,80) | слияние, только с правом apply |
| ДУБЛЬ? | обоюдное `DUP_T`..`MERGE_T` (0,72–0,80) | обратимая пометка «возможный дубль» в оба файла |
| ВЛОЖЕНИЕ | одна сторона ≥ 0,85, другая < 0,5 | взаимные ссылки «часть более широкой темы / частный эпизод» |
| ГРАНИЦА | обе ≥ 0,45 | только в отчёт |

Слияние: хроника объединяется, статус берётся свежий, рукописная суть дубля переносится в канон блоком
`## Суть дубля «X»`, от дубля остаётся переадресация.

## Кто зовёт
- **После встречи** — `graph_updater`. Фокус — ядра этой встречи против всех, O(k×n).
- **Ночь** — `scripts/tier3_cores.py --auto` из `nightly.sh`. По будням `--since-last`: фокус — ядра, изменённые с
  отметки, плюс долг `#pending`. По воскресеньям — полный прогон.
- **Вручную** — тот же CLI, `--apply` для слияния.

Включает ревизию флаг `sufler.tier3`. Значение по умолчанию задаёт пресет установки (`ModelPresetPolicy`).
Необратимое слияние разрешает только `sufler.tier3_auto_apply`, строго `True` (`auto_apply_allowed`) — одна точка
для дневного и ночного пути.

## Состояние ночи
Состояние лежит в `logs/tier3_last_run.json`:
- `<граф>` — время прошлого прогона;
- `<граф>#pending` — ядра, чьи пары не досудились (отказ модели, потолок времени);
- `<граф>#judged` — пары, досуженные оборванным прогоном.

`no_work` двигает отметку и переносит долг без изменений. Иначе граф из одних автостатусов каждую ночь читался бы
полным прогоном, а долг стирался бы молча.

## Страховки
- Перед любой правкой файлы копируются в `Ядра/.tier3_backup/<дата>/`. Хранится `BACKUP_KEEP` (20) последних
  папок. Точечные каталоги пропускают обходы графа: `graph_links.read_notes` (доктор графа), досье, поиск,
  `vault_search`.
- Ядро-«хаб», к которому NLI притянул ≥ `HUB_LIMIT` (3) вложений, не трогается автоматически.
- Если файл ядра изменился с момента чтения (`_stale`), пара пропускается: её разберёт следующая ночь.
- Без NLI-модели или эмбеддера — `unavailable`, пайплайн живёт.

## Возврат к широкому суду
Ядра без своей сути вернуть в суд можно только после замера точности: 20 уверенных пар, явных дублей не меньше 90 %.
Кандидат на смену эмбеддера для дедупа ядер — Giga-Embeddings-480M (09.10: AUC 0,501 против 0,227 у bge-m3), его
нужно мерить отдельно.

## Известные ограничения
- Секции читаются строгим заголовком `## <имя>\n`: CRLF, хвостовой пробел или лишний пробел после `##` снимают суть с
  суда. Слияние (`_merge`) разбирает тот же строгий формат. Чинить нужно одним разборщиком секций для читателя и
  писателя, а не терпимым чтением в одном месте: терпимое чтение впускает в слияние ядро, которое `_merge` разобрать
  не может.
- Нечитаемый файл ядра роняет прогон: отметка не двигается, следующая ночь повторит работу. Молчаливый пропуск
  хуже — он вычёркивает ядро из долга.
- На инкременте строка «чисто — судились N из M» показывает судимых кандидатов графа, а не размер фокуса.
