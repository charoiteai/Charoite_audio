# Карточка темы: как менялась работа

В экране «Память» нажатие на сквозную тему открывает карточку внутри приложения.
Карточка читает существующее досье, а при его отсутствии — ядро. Новые вызовы
моделей, облачные разрешения и запись в граф не нужны.

## Первая версия

- Состояние **по сводке**, а не обещание актуальности на момент открытия.
- Как менялась тема: существующая хроника, в порядке исходного документа.
- Записанные решения и открытые вопросы/поручения — отдельные разделы.
- Явно записанные неясности; отсутствие раздела означает отсутствие сведений,
  а не отсутствие противоречий. Штатный генератор досье пока не создаёт этот раздел.
- Участники и правки автора показаны отдельно. Карточка не применяет правки
  автора автоматически к другим разделам: читатель видит исходную оговорку.
- Дата сборки досье; если её нет, дата изменения документа с другой подписью.
- Ссылки из каждого раздела открывают исходные Markdown-файлы. Это ссылки
  документа, не независимо проверенные доказательства; просмотр не проверяет
  соответствие утверждения источнику и не ищет точный аудиофрагмент.
- Сохраняется кнопка открытия исходного документа в привычном редакторе.

Не найденные и неоднозначные ссылки видны, но отключены. Источники разрешаются
только внутри графа; скрытые пути, traversal и внешние symlink запрещены.
Повреждённое UTF-8 досье даёт ошибку, а не незаметную подмену старым ядром.
При нескольких одноимённых досье показано ядро: произвольного выбора нет.

## Проверка на Mac

`cd app && swift test --filter TopicCardTests`

В «Память» открыть тему демо-графа: без досье видны статус, история и следующий
шаг ядра; остальные разделы сообщают, что сведений нет. На графе с досье
проверить дату сборки, авторскую оговорку и ссылки из отдельных разделов.
Закрыть карточку Escape; исходный документ должен по-прежнему открываться
кнопкой. Повторное открытие читает документ заново.

## Следующий этап

Действующее решение требует явной связи «заменяет предыдущее» и проверки
источников: последняя строка хроники сама по себе не является таким решением.
Для обещаний нужна привязка поручения к источнику и свидетельство выполнения;
отсутствие свидетельства нельзя называть невыполнением. Автоматический поиск
противоречий и аудиопереходы добавляются после отдельного набора проверок.

Текущая точка входа использует четыре свежих ядра существующей колонки.
Полный каталог тем и фильтр по проекту — последующая работа; первая версия
не добавляет второй скан всего графа при каждой перерисовке интерфейса.
