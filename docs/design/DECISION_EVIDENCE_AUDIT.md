# Проверяемое основание решений

Первый этап пункта 5 — read-only аудит экспортированных фактов. Каждому факту
нужны id, kind (decision/action/proposal), дата, путь источника, дословная
цитата; необязательные поля source_sha256 и supersedes.

`python scripts/decision_evidence_audit.py --graph /path/to/graph records.json`
проверяет наличие цитаты, неизменность источника по SHA-256 и корректность
явных связей замены: существование предшественника, типы, порядок дат, циклы.
JSON идёт в stdout; exit 1 при находках, exit 2 при неправильном входе.
Граф и документы не изменяются; модели и сеть не используются.

Проверка цитаты нормализует Unicode и пробелы, сохраняет отрицания, числа,
регистр и пунктуацию. Это не проверка смысла: semantic_support всегда
not_checked. Наличие цитаты не делает предложение принятым решением и
не означает, что последняя запись действует сейчас.

Нельзя выводить невыполнение поручения из отсутствия подтверждения. Нельзя
автоматически удалять предыдущий факт по более поздней дате. Вывод аудита
предназначен для ревью и будущего контрольного этапа перед записью в граф.
Извлечение таких записей из текущих Markdown-хроник и включение проверок
в основной конвейер — дальнейшая работа после размеченных примеров.
