# Настройка диаризации спикеров

*[English](DIARIZATION.md) · **Русский** · [中文](DIARIZATION.zh.md)*

Charoite делает два прохода диаризации:

1. **Живой** (во время встречи): модель спикер-эмбеддингов в реальном
   времени помечает чанки как «Собеседник 1/2/…». Нужна эмбеддинг-модель
   ERes2Net в формате ONNX по пути `models/diar/embedding.onnx`
   (выход 512 измерений, вход 16 кГц). Взять её можно в
   [проекте 3D-Speaker](https://github.com/modelscope/3D-Speaker)
   (ERes2Net, обученная на CN-Celeb/VoxCeleb, хорошо работает для
   русского и английского) и экспортировать/скачать как ONNX.
2. **Офлайн-перепроход** (после Стоп): вся запись заново диаризуется
   поканально, эхо между микрофоном и системным звуком отфильтровывается,
   микрофрагменты вливаются в соседние реплики, а имена, прозвучавшие в
   разговоре, расставляет локальная LLM. Результат заменяет живой
   черновик стенограммы.

Без `models/diar/embedding.onnx` Charoite всё равно работает: вместо
меток по голосам используются метки каналов (вы и другая сторона).

Настройка (`config/config.yaml`):

- `live_diarize_threshold` (по умолчанию 0.45) — косинусная близость, при
  которой чанк прикрепляется к уже известному голосу; поднимите порог,
  если разные люди склеиваются в одного, опустите — если один человек
  постоянно распадается на двух.
