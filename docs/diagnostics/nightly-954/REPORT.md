# №954 — причины отказов ночной сборки

- Вместо общего «модель-молчала» — нейтральный статус отказов сборки и закрытая JSON-сводка этапов/причин.
- Раздельно считаются темы скана, входы в сборку, прежние попытки для порога, local completion, stream адаптера и итоговые отказы.
- Отказ допуска до stream, timeout, пустой ответ, формат/аудит и IO не смешиваются; один stream не доказывает HTTP-доставку.
- Сводка не содержит имён, путей, промптов, ответов и текста исключений; прерывание сохраняет завершённый префикс.
- Порог max(3, attempts//10), combined scan-failed exit 4, очередь, лимиты и защитные двери сохранены.

- Адресная приёмка: 260 PASS / 57.97 с; после дополнения scan-time учёта — 77 PASS / 5.17 с, включая 21 causal test.
- OUTPUT Terra C0/I1/M1, Luna C0/I0/M0; находки подтверждены до (2 FAIL/2 PASS), исправлены, после — 209 PASS / 5.85 с.
- Первый PR-CI остановлен красной базой: устаревшая фраза в regression-тесте; после обновления ожидания — 92 PASS / 7.60 с.
- Следующий CI выявил 2 обязательных реестра и 15 critical + 1 noncritical survivors. Исправления: 173 PASS; 11 сохранённых операторов killed / 0 survived.
