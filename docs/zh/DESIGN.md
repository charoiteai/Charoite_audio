# Charoite 设计系统

*[English](../DESIGN.md) · [Русский](../ru/DESIGN.md) · **中文***

两个平台，同一个性格：macOS 应用与 iPhone 伴侣应用由同一套设计令牌构建。代码中的权威来源是各 target 里的 `Theme.swift`（`app/Sources/CharoiteApp/Theme.swift`、`app-ios/Sources/CharoiteiOS/Theme.swift`）；本文档是人类可读的描述及其背后的约定 — 以代码为准。

## 调色板

| 令牌 | 值 | 角色 |
|---|---|---|
| `accent` | `#6366F1` 靛蓝 | 操作：按钮、链接、激活状态 |
| `violet` | `#8B5CF6` 紫龙晶 | 性格：渐变、品牌点缀 |
| `brand` | accent→violet 渐变 | “活跃”操作：录音、首次运行 |
| `sky` | `#0EA5E9` | Claude 云面板 — 与本地明确区分 |
| `ok` | `#059669` | 成功、绿色状态 |

语义色（录音/错误的红色）用系统颜色，不属于品牌色。背景与文字使用平台的系统材质（`.bar`、`.background`、`secondary`）：深色模式无需额外适配，且始终保持真实。

## 字体排印

使用平台系统字体（SF），不引入自定义字体：这款应用是伴随工作的工具，不是展示橱窗。

- 面板标题：`caption.weight(.semibold)`，次要颜色（macOS 端 SuflerView 里的 `paneTitle`）。
- 大写标签：`caption2.semibold` + 字距 0.8（iOS 端 `Theme.label`）。
- 录音计时器：细字重（`thin`/`weight(200)`），等宽数字。
- 正文：系统字号；再长的俄语字符串也绝不挤压。

## 几何规格

- 圆角（`Theme.radius` / `Theme.radiusCard`）：输入框与小元素为 8；卡片与聊天气泡为 12；胶囊控件为药丸形。
- 内边距：面板内部默认 12，窗口边缘 14–16。
- 卡片：系统表面填充；阴影只给“活跃”元素（录音按钮），静态卡片一律不加。

## 组件

- **面板**：图标 + 大写标题（`paneTitle`），次要颜色，`.bar` 背景；复制按钮只放在一次性内容处（提示、Claude），信息流上不放。
- **录音按钮**：圆形/胶囊形，用 `brand` 渐变加柔和的 accent 色阴影；录音进行时改为系统红色，阴影关闭。
- **空状态**：一个图标加一行文字，说明会出现什么、何时出现；不用插画。
- **投递/队列状态**：屏幕底部一行文字，语言平实；不用模态对话框。

## 界面文案语气

语言鲜活，不带官腔套话。按钮点明操作，状态陈述结果，错误说明发生了什么、该怎么办。不使用“请”“抱歉”“已成功”这类词。

## 原则

1. 本地静默，云端可见：任何离开本机的东西都有自己的颜色（`sky`）和关闭开关。
2. 没有什么会无声消失：用队列与状态取代静默失败。
3. 不做声纹生物识别 — 设计上也如此体现：没有任何“声纹档案”界面。
4. 深色模式不是简单反色，而是同一套令牌配合系统材质。
