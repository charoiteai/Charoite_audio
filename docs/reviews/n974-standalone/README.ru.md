# Отдельное исправление Linux pytest CI

Ветка основана на актуальной main2106ed52. Перенесён только двухфайловый патч:
фиксированный runnerubuntu-24.04 для полного Linuxpytest и строгая проверка
метки, единственного шага pytest и прежней полной команды. Runtime955, его
история и незавершённая проверка дочернего FD в эту ветку не входят.

Исходные blobs обоих файлов совпали с базой прежнего INPUT. На новой ветке
обязательны свои адресные проверки, независимые OUTPUT и полный CI того же
снимка. Реальный Linux24.04 ещё должен подтвердить пригодность среды; локальная
проверка YAML этого не доказывает. Пороги, зависимости, фильтры, macOS и мутации
не изменены. Публикация идёт отдельным обычным PR в main после OUTPUT.
