# Исправления по повторному аудиту 11 октября 2026

База проверки: `main` на коммите `5149770552b2b49c8b48dec12ad44a8351028cbf`.

## Исправленные проблемы

1. Валидный JSON индекса досье с повреждённой структурой мог оборвать обычный
   поиск графа. Чтение теперь проверяет тип контейнера, темы и ключей;
   пригодные записи сохраняются рядом с повреждёнными. Дополнительные поля
   старых индексов не становятся обязательными.
2. Отказ записи одного досье обрывал остальные темы и публикацию индекса.
   Ошибки каталога, резервной копии, записи документа и индекса теперь
   учитываются отдельно от отказов модели. Обход продолжается, прежнее
   досье сохраняется при отказе его записи, а entry point возвращает код 2
   при любой такой ошибке хранения.
3. Несовместимые размерности кэша и текущей модели считались выполненными
   сравнениями, давая ложный вердикт «пусто». Поиск учитывает только
   совместимые сравнения; несовместимые документы возвращаются в очередь.
   Частичная пересборка сохраняет в одном блобе только одну размерность.
   Неконсистентные ответы внутри пачки и между пачками останавливают сборку.
   Формат дискового кэша не меняется.

  18 проходят.
- Повторный набор из 16 тестовых модулей: **671 passed**, включая существующие
