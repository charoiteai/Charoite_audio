## Подтверждённые дефекты

### A1 · P1 · Потоки одного процесса делят временный файл

**Где:** `src/charoite_graph/safe_write.py`, `write_text`, `copy_if_changed`.

Имя временного файла содержало только PID. Два потока, записывающие один
целевой файл, использовали один tmp: второй поток заменял или удалял его,
после чего первый получал `FileNotFoundError`. Это общий шов записи графа,
статусов и производных, поэтому последствия выходят за один документ.

**Исправление:** уникальное имя на каждый вызов, рядом с целевым файлом.
Сохранены атомарный `replace`, режимы доступа, метаданные копирования,
очистка tmp и существующий оптимистический гейт версии.

**Регрессия:** `test_threads_writing_one_target_have_independent_temporary_files`
в `tests/test_safe_write.py`: барьеры воспроизводят пересечение двух потоков
для обычной записи, записи с `mode=0600` и копирования. Проверяются ошибки,
содержимое результата и отсутствие оставшихся tmp.

### A2 · P1 · Паспорт может смешать новую производную со старым источником

**Где:** `src/live_sidecar.py`, `attest`.

Хеш байтов и хеш источника записывались двумя независимыми `remember`.
Отказ второй записи оставлял новый хеш байтов со старым хешем источника.
Такой паспорт мог неверно объявить файл свежим для прежнего источника.

**Исправление:** оба поля публикуются одним существующим `merge`, под
его блокировкой, одной атомарной записью JSON.

**Регрессия:** `test_attest_publishes_the_byte_hash_and_source_hash_together`
в `tests/test_derivative_passport.py`: второй вызов записи отказал бы;
первая опубликованная версия уже обязана содержать правильную пару.

### A3 · P1 · Правка во время ответа модели перезаписывается

**Где:** `meeting_archive._build_summary`, `retro_fill.process`,
`live_sidecar.write_derivative`.

Снимок целевого файла снимался после генерации, на входе в писатель.
Человек мог изменить саммари, разбор или тезисы, пока отвечала модель;
писатель принимал эту правку за допустимую исходную версию. Так же
затирался новый файл, созданный человеком во время генерации.

**Исправление:** вызывающие снимают версию до модели и передают её через
`expect` / `expect_absent`. Писатель отказывает при расхождении до изменения
`.prev`, затем использует существующую проверку перед `replace`.
Снимок `retro_fill.process` включён в критическую зону мутационной карты:
это расширяет контроль реального решения о перезаписи, а не исключает его.

**Регрессии:** `test_summary_keeps_human_edits_made_while_the_model_answers`
и `test_retro_keeps_a_file_edited_during_generation`: шесть сценариев для
саммари/разбора/тезисов, существующего и отсутствовавшего файла. Поддельная
модель делает ручную правку до возврата ответа. Проверяются сохранение
правки, паспорта и, для саммари, прежнего `.prev`.

**Граница:** `(mtime_ns, size)` — оптимистическая проверка, не файловая
транзакция. Уже документированное короткое окно между проверкой и
`replace`, а также изменения с сохранёнными mtime/размером остаются.
Эта правка закрывает длительное окно генерации в перечисленных путях.

### A4 · P2 · Переименование не добавляет тему в часть YAML-алиасов

**Где:** `scripts/rename_meeting.py`, `apply`.

Регулярное выражение обслуживало только `aliases: [...]`. При блочном
списке или отсутствующем поле новая тема не попадала в алиасы заметки.
Вход `pretty_and_slug` уже очищает кавычки и обратные слеши: инъекция YAML
через обычный ввод здесь не подтверждена.

**Исправление:** существующий `frontmatter.with_aliases` вместо ручной
сборки YAML. Сохраняются прежние алиасы и тело заметки.

**Регрессия:** `test_rename_keeps_yaml_valid_and_adds_a_quoted_title` в
`tests/test_rename_meeting.py`: inline, блочный список, отсутствующее поле;
разбор результата как YAML и сохранение старого алиаса. Inline — контроль.

### A5 · P2 · Повреждённые времена ломают оценку завершённой обработки

**Где:** `src/meeting_processing.py`, `MeetingStatusStore.typical_duration`.

`float(None)`, строки и контейнеры выбрасывали исключение из оценки,
которую использует doctor. `Infinity`, bool и отсутствующее время начала
могли засчитываться как завершённые образцы и искажать оценку.

**Исправление:** неверные, не конечные времена, bool и отсутствующее
начало пропускаются; минимум выборки считается по пригодным образцам.
Нулевое время начала допустимо и сохраняет прежний контракт.

**Регрессии:** `test_typical_duration_ignores_corrupt_times` и
`test_corrupt_times_do_not_count_as_completed_samples` в
`tests/test_unfinished_meetings.py`. `NaN` — контроль: прежний код уже
не включал соответствующий span в медиану.

### A6 · P2 · Проверяется лишь первая координата эмбеддинга

**Где:** `src/charoite_graph/embed_door.py`, `_vectors_ok`.

Вектор `[1.0, "не число"]`, вложенные значения, bool, `NaN`, бесконечности
и не представимый как float большой int проходили транспортный шов.
Дальше потребители получают ошибки арифметики либо некорректную близость.

**Исправление:** каждая координата должна быть конечным int/float без bool;
переполнение преобразования тоже означает отказ. Сохранён существующий
путь диагностического сообщения и возврата пустого результата.

**Регрессия:** `test_embedding_transport_rejects_invalid_components_after_the_first`
в `tests/test_embed_door.py`: девять ответов сервера через публичный
`Embedder.run`, с проверкой результата и сообщения об отказе.
