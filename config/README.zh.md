# 配置预设

*[English](README.md) · [Русский](README.ru.md) · [**中文**]*

复制任一预设为 `config/config.yaml`，然后填入 `user_name` 和 `graph_dir`。

- `config.example.yaml` — 俄语默认：GigaAM STT（俄语 SOTA），俄语文档。
- `config.example.en.yaml` — 英语：Parakeet STT，英语文档和提词角色。
- `config.example.zh.yaml` — 中文：Whisper STT，中文文档；默认 LLM Qwen 的中文是母语级。

每个键都在文件内有注释说明。`config.yaml` 本身在 git-ignore 中——您的设置不会离开本机。
