# Тесты

*[English](README.md) · [**Русский**] · [中文](README.zh.md)*

```bash
.venv/bin/python -m pytest tests/ -x -q
```

Без сети и без моделей — всё тяжёлое замокано. Два сторожевых набора, о которых стоит знать: `test_privacy_defaults.py` (молчание в конфиге значит «облака нет») и `test_cloud_call_sites.py` (каждая точка, откуда запрос может уйти с машины, зарегистрирована и проверяется). Swift-тесты приложений живут рядом с приложениями и запускаются через `swift test` / `xcodebuild test`.
